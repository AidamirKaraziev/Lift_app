# Передача: фронт живёт на ручках `draft` и `pdf`, остался прогон на стеке

## Сделано и проверено

- Кнопка «Приказ о назначении» в обеих карточках (админ `object_page.dart`,
  прораб `object_page_foreman.dart`) получает `objectId` из `viewObjectPage['id']`,
  по нажатию тянет `GET /object/{id}/appointment-order/draft`, крутит индикатор,
  открывает диалог с ответом; ошибка — снэкбар словами.
- «Скачать PDF» отдаёт правки в `POST …/appointment-order/pdf`, к `url` из
  ответа дописывается схема (`ApiConfig.withScheme`), ссылка открывается
  `launchUrl(mode: externalApplication)` — вкладка на вебе, просмотрщик на
  телефоне. На время сборки кнопка выключена («Собираем PDF…» + спиннер);
  ошибка — красная строка над кнопками, вне прокрутки, правки остаются.
- Модель `model/appointment_order_draft.dart`: `fromJson`/`toJson` под снимок
  OpenAPI; `date` — секунды местной полуночи; должности в родительном падеже;
  `fromObjectMap` удалён.
- Репозиторий `repository/appointment_order_repository.dart` — через `Api`
  (`helper/api_client.dart`), не dio; `send`/`post` подменяются в тестах.
- Тесты `frontend/test/object/` — 13 (модель 3, репозиторий 5, диалог 5),
  `flutter test test/object` зелёный; `dart analyze` по затронутым файлам чист;
  `flutter build web` собирается. Коммит `6ab0794`.
- Индикатор и строка ошибки смотрели глазами в превью `lib/dev/appointment_order_preview.dart`
  (там «Скачать PDF» на раскладе «Нет механика» нарочно падает через секунду).
