# Выключенный бэк за nginx — это 502 от прокси, а не обрыв сети

Репозиторий фронта, переводящий ответ ручки в слова для человека, должен
считать `502/503/504` тем же, чем и исключение сети
(`repository/appointment_order_repository.dart`):

```dart
try {
  response = await request().timeout(timeout);
} catch (_) {
  throw const AppointmentOrderException('Не удалось связаться с сервером');
}
switch (response.statusCode) {
  case 200: break;
  case 401: case 403:
    throw const AppointmentOrderException('Недостаточно прав или истёк вход');
  case 404:
    throw const AppointmentOrderException('Объект не найден');
  case 502: case 503: case 504:
    // выключенный бэк за nginx — не обрыв сети, а 502 от прокси
    throw const AppointmentOrderException('Не удалось связаться с сервером');
  default:
    throw AppointmentOrderException('Сервер ответил ошибкой ${response.statusCode}');
}
```

## Почему так

На собранном стеке и на проде перед бэком стоит nginx
([[Docker Compose - postgres + backend + фронт с nginx]]). Когда контейнер
бэка погашен, запрос **не** падает исключением — nginx через ~3 секунды
честно отвечает `502 Bad Gateway`. Ветка «нет сети» в `catch` при этом не
срабатывает, и без своих `case` человек видел бы «Сервер ответил ошибкой
502». Обнаружилось в E04·S05, когда сценарий «выключенный бэк» проверяли
руками: `docker stop` бэка дал не таймаут, а быстрый 502.

## Что важно не забыть

- Проверять этот сценарий только на `make up` — в `flutter run` против
  `uvicorn` без прокси выключенный бэк действительно даёт исключение сети,
  и ветка `502` выглядит лишней.
- `504` — это таймаут самого nginx (60 с по умолчанию), а свой `timeout`
  на запросе короче; но при долгой сборке PDF первым может ответить прокси.
- `401` и `403` в одном сообщении: репозиторий не различает истёкший вход и
  чужой объект, потому что в обоих случаях человеку делать одно — выйти
  и войти или взять другой объект.

Применимо к каждому репозиторию с переводом кодов в слова: лента работ,
отчёты, выгрузки — везде, где сейчас `catch` ловит только исключение.
